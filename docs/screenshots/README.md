# Screenshots

The main README embeds the four images below. Capture them from a real browser
(Live Server is ideal) so dark mode, the lightbox, and the scroll-reveal sections
all render. Save each with the exact filename listed.

Use a desktop window around 1280px wide unless noted. PNG format.

| Filename               | What to capture                                                                                  |
| ---------------------- | ------------------------------------------------------------------------------------------------ |
| `home-light.png`       | Home page in light mode, top of the page (hero plus the three feature boxes).                    |
| `history.png`          | History & Culture page, ideally scrolled to show a section with a photo and the interactive map. |
| `home-dark.png`        | Home page again with dark mode on (use the floating toggle, bottom-right).                       |
| `gallery-lightbox.png` | Gallery page with the lightbox open (click any carousel image).                                  |

Optional extras you can add later: a mobile view with the hamburger menu open, and
the contact form showing a validation message.

After saving the files here, the images will appear in the main README.
