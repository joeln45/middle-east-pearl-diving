## 📖 About

**Middle East Pearl Diving** is a virtual museum and educational resource that tells the
story of pearl diving across the Gulf — a centuries-old occupation that shaped the culture
and economy of nations such as the UAE, Bahrain, Kuwait and Qatar before its decline in the
1930s. The site combines historical context, modern industry insight, and rich visuals to
preserve the legacy of this endangered tradition.

Originally built as a coursework submission for **CSCU9X5 UX Design** at the University of
Stirling, this repository documents its evolution into a polished, accessible, deployed
portfolio piece.

## 👥 Target audience

- History and culture enthusiasts
- Educational institutions and students
- Maritime heritage researchers
- Cultural tourism professionals

Designed around two personas: **Joshua**, a 24-year-old history student researching on a
laptop, and **David**, a 35-year-old tourist browsing on his phone before a trip to the UAE.

## ✨ Features

- 📱 Responsive, multi-page layout (Home, History & Culture, Modern Industry, Gallery, Contact)
- 🧭 Accessible navigation with a mobile hamburger menu
- 🖼️ Image gallery with an auto-advancing carousel
- ✉️ Contact form with validation
- 🎨 Marine-inspired colour palette with high contrast for readability

> 🚧 More features (dark mode, gallery lightbox, scroll animations, interactive map) are
> being added during the portfolio upgrade — see the roadmap below.

## 🛠️ Tech stack

- **HTML5** — semantic markup
- **CSS3** — custom properties, Flexbox/Grid, responsive design
- **Vanilla JavaScript** — no frameworks
- **Google Fonts** — Roboto

## 🚀 Getting started

```bash
git clone https://github.com/joeln45/middle-east-pearl-diving.git
cd middle-east-pearl-diving
```

Then open `index.html` in your browser, or use the **Live Server** VS Code extension
(right-click `index.html` → *Open with Live Server*) for auto-refresh while editing.
